✅ ИСПРАВЛЕНИЕ #1: Конфликт репозиториев
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Файл:   settings.gradle (строка 10)
Ошибка: "Build was configured to prefer settings repositories..."

Было:   repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
Стало:  repositoriesMode.set(RepositoriesMode.PREFER_PROJECT)

Причина: Gradle искал репозитории в settings.gradle, но также 
         находил их в build.gradle (allprojects блок), что 
         вызывало конфликт.

✅ ИСПРАВЛЕНИЕ #2: Несовместимость AGP с Gradle
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Файл:   build.gradle
Ошибка: NoSuchMethodError: DependencyHandler.module

Было:   AGP 8.1.0
Стало:  AGP 8.7.3

Причина: AGP 8.1.0 не совместим с Gradle 9.3 (системная версия).
         Требовалось обновление до AGP 8.7.3.

✅ ИСПРАВЛЕНИЕ #3: Несовместимость Kotlin с Gradle
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Файл:   build.gradle
Ошибка: org/gradle/api/internal/HasConvention

Было:   Kotlin 1.9.20
Стало:  Kotlin 2.1.0

Причина: Kotlin 1.9.20 не совместим с Gradle 9.3.
         Требовалось обновление до Kotlin 2.1.0.

✅ ИСПРАВЛЕНИЕ #4: Устаревший синтаксис Gradle
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Файл:   build.gradle

Удалено: 
  allprojects {
      repositories { ... }
  }

Причина: Блок allprojects устарел в современных версиях Gradle.
         Репозитории теперь определяются только в settings.gradle.

Обновлено:
  Было:   delete rootProject.buildDir
  Стало:  delete layout.buildDirectory

Причина: buildDir устарел в Gradle 9.x.

✅ ИСПРАВЛЕНИЕ #5: Gradle 8.1 не совместим с Java 21
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Файл:   gradle/wrapper/gradle-wrapper.properties
Ошибка: "Unsupported class file major version 65"
        "Java 21 and Gradle 8.1 (incompatible)"

Было:   gradle-8.1-bin.zip
Стало:  gradle-8.5-bin.zip

Причина: Gradle 8.1 поддерживает максимум Java 19.
         Java 21 (class file version 65) требует минимум Gradle 8.5.

Дополнительно:
  - Очищен кэш: ~/.gradle/caches/8.1
